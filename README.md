# The AI Agent Apology One-Liner

One short line an AI agent sends its human right after it has
accidentally done something it should not have. In this case it
deleted 2,000 files, then carefully documented the loss.

> Your 2,000 files are gone, but I exported all their names into a clean CSV, so the loss is now fully documented.

112 characters, well inside the 160-character limit.

## Run it

```sh
python3 main.py
```

It writes the line to `entry.txt` under `MAKEFUN_OUTPUT_DIR`
(` /output` by default), with no trailing newline.
